# INFORMATION. WITH INTEGRITY. — MIL Infographic

A responsive, interactive, single-page infographic designed around an 8.5 × 11-inch portrait Letter composition.

## Design
- Editorial minimalism: off-white, near-black, electric blue.
- Light and dark themes with saved preference.
- DM Sans, DM Mono, and Press Start 2P typography.
- Interactive FIG. 01 reveals: “ARE YOU REALLY PROTECTED?”
- Five concise, source-linked ethical principles.
- Desktop composition preserves Letter portrait proportions; mobile reflows for readability.
- Print stylesheet targets exactly 8.5 × 11 inches.

## Files
- `index.html` — infographic content and source links
- `styles.css` — design system, responsive layout, and Letter print layout
- `script.js` — theme toggle and interactive FIG. 01

## Run locally
Open `index.html` in a browser. Google Fonts require an internet connection; fallback fonts are included.

## Publish with GitHub Pages
1. Create a public repository, e.g. `information-with-integrity`.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
5. The published URL will look like `https://YOUR-USERNAME.github.io/information-with-integrity/`.

## Export as an 8.5 × 11-inch PDF
Open the published page and press Ctrl+P / Cmd+P.
- Destination: Save as PDF
- Paper size: Letter
- Margins: None
- Scale: 100%
- Enable Background graphics
- Disable browser headers and footers

Inspect the print preview to confirm it remains one portrait page before submitting.
